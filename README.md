# Foobar2000 Song Name Fetcher

A small utility that extracts the song name from the currently playing track's title in Foobar2000.

## Overview

This project was created to simplify retrieving song names from Foobar2000, making it easier to identify and reference currently playing music.

## Development

This project was developed with assistance from AI tools, which generated the majority of the code. I defined the intended functionality and used AI-assisted development to create the utility.

## Purpose

A personal utility project exploring practical automation and the use of AI-assisted software development to solve everyday problems.
